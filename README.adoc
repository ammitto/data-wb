= Ammitto World Bank debarment data

image:https://github.com/ammitto/data-wb/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-wb/actions/workflows/fetch.yml"]

This repository stores World Bank debarment data as YAML for Ammitto.
`processed/` holds one file per firm or individual in the World Bank's
Listing of Ineligible Firms and Individuals.

== Source

* Publisher: The World Bank
* List page: https://www.worldbank.org/en/projects-operations/procurement/debarred-firms
* Data downloaded from the World Bank JSON service behind that page

The listed firms and individuals are debarred and ineligible to participate in
World Bank financed contracts for the periods indicated, either as a result of
World Bank sanctions proceedings or by cross-debarment under the Agreement for
Mutual Enforcement of Debarment Decisions with other development banks.

== Contents

`processed/` holds one file per listing, named after its supplier ID:
`processed/wb-1000672.yaml` is supplier 1000672.

`processed/_index.yaml` lists every file, with the time of the last fetch.

The keys are field names of the World Bank service, except `entity_type`,
which is derived. Several keys are internal codes the World Bank does not document on the
list page; they are listed with the values found, without an assumed
meaning.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `supp_id` | integer | Supplier ID
| `supp_name` | string | Name of the firm or individual
| `supp_pre_acrn`, `supp_post_acrn` | string | Prefix or suffix of the name, such as `MR` or `LLC`
| `supp_type_code` | string | Supplier type code: `I` for an individual; `F`, `U` or `C` otherwise
| `entity_type` | string | `person` when `supp_type_code` is `I`, otherwise `organization`
| `country_name`, `land1` | string | Country, by name and two letter code
| `supp_addr`, `supp_city`, `supp_state_code`, `supp_prov_name`, `supp_zip_code`, `supp_post_code` | string | Address
| `add_supp_info` | string | The list's "Additional Firm Info" column, such as other names or a note marker like `*722`
| `debar_from_date`, `debar_to_date` | string | Ineligibility period, `YYYY-MM-DD`; `2999-12-31` as `debar_to_date` marks an open-ended debarment, whether its `ineligibly_status` is `Ongoing` or `Permanent`
| `ineligibly_status` | string | `Ongoing` or `Permanent`, where given
| `debar_reason` | string | Grounds, such as `Fraudulent and Obstructive Practices`
| `elig_stat`, `supp_elig_stat` | string | `DEBARRED` or `X-DEBARRED`
| `crpd_match` | string | `Y` or `N`
| `crpd_stat`, `inelig_flg`, `debar_type`, `un_supp_flg`, `legacy_flg`, `mandt` | string | Internal codes, as published: `crpd_stat` `CLEARED`; `inelig_flg` `D` or `X`; `debar_type` `O` where present; `un_supp_flg` and `legacy_flg` `N`; `mandt` `300`
|===

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/wb-*.yaml").sort.each do |path|
  record = YAML.safe_load_file(path)
  period = [record["debar_from_date"], record["debar_to_date"]].join("..")
  puts [record["supp_id"], record["supp_name"], record["country_name"], period].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("processed/wb-*.yaml")):
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    period = f'{record["debar_from_date"]}..{record["debar_to_date"]}'
    print(record["supp_id"], record["supp_name"], record["country_name"], period, sep="\t")
----

The same list, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/wb.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 07:00 UTC and commits any change to `processed/`. It runs with
`--prune`, so a listing the World Bank has removed is deleted here on the next
fetch.

`update.log` is an older log that the daily fetch no longer updates.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.3 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch wb --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/wb[`lib/ammitto/sources/wb/`].
Report data or source-list issues in
https://github.com/ammitto/data-wb/issues[this repository].
